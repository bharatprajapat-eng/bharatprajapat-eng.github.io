# Bharat Prajapat — Personal Portfolio Website

This repository hosts the official personal portfolio website for **Bharat Prajapat**, Full-Stack & AI Systems Engineer.

🌐 **Live Website**: [https://er-prajapat.github.io/](https://er-prajapat.github.io/)

---

## 🚀 About the Portfolio
- **Clean, Modern & Accessible**: Minimalist developer aesthetic with dark and light theme options.
- **High Performance**: Built with zero external framework dependencies (Vanilla HTML5, Modern CSS Variables, ES6 JavaScript) for ultra-fast load times.
- **Project Showcase**: Highlights active work in autonomous AI coding agents, PyTorch deep learning models, cloud IaC (Terraform), and enterprise API integrations.
- **Automated Deployment**: Served directly via **GitHub Pages**.

---

## 🛠️ Tech Stack
- **HTML5 & Modern CSS3** (CSS Variables, Flexbox, CSS Grid, Glassmorphism)
- **Vanilla JavaScript** (Theme persistence, smooth state toggling)
- **GitHub Pages** (Continuous deployment from `main` branch)
