## 🧭 About This Site
This is the personal engineering portfolio, architecture showcase, and project hub of **Bharat Prajapat**. Built with pure vanilla web technologies (HTML5, modern CSS3 variables, ES6 JavaScript) for ultra-fast load times, complete responsiveness, zero runtime dependencies, and high accessibility.

### Highlights
- **Multi-Cloud Architecture Focus**: Covers enterprise modernization across Microsoft Azure, Google Cloud (GCP), AWS, and on-premises VMware vSphere.
- **Deep-Dive Case Studies**: Real problems, architectural strategies, and implementation outcomes across Kubernetes, Universal CI/CD (500+ services), Workload Identity Federation, and Edge Ingestion.
- **Interactive Developer Console**: Built-in terminal simulator supporting commands like `skills`, `journey`, `cases`, `projects`, and `contact`.
- **Engineering Philosophy**: The 7 foundational principles guiding reliable, cost-aware systems architecture.
- **Dark / Light Theme**: Clean toggle with persistent local storage.
